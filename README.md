# Sobom Creatives — Flagship Digital Product & UI/UX Landing Page

A bespoke, high-converting digital product design studio landing page created for **Sobom Creatives**.

Designed with award-winning aesthetic standards (inspired by Awwwards, Dribbble, and contemporary high-end creative agencies), featuring dark editorial typography, glassmorphism, dynamic mesh gradients, interactive project modals, and a live pricing/timeline calculator.

---

## 🌟 Highlights & Features

- **Editorial Dark Aesthetic**: Deep zinc tones (`#07080B`), subtle noise texture overlays, and multi-layered radial mesh glow orbs.
- **Interactive 3D Tilt Card**: Hero visual mockup dynamically tilts based on mouse cursor coordinate tracking.
- **Dynamic Project Portfolio with Category Filters**:
  - Filter across SaaS & AI, Mobile Ecosystems, Fintech, and Immersive Web.
  - Interactive **Case Study Modal** showcasing challenges, solutions, deliverables, and verifiable growth metrics.
- **Transparent Project Cost & Timeline Estimator**:
  - Real-time client scope estimator (Objective, Scale, and Add-ons like Motion & Front-end code).
  - Automatically calculates estimated investment brackets and turnaround weeks.
  - "Lock In This Scope" button automatically pre-fills the inquiry brief and smoothly guides the user to contact.
- **Client Inquiry Form & Confirmation Flow**:
  - Full client questionnaire with service tags, company details, validation, and a confirmation modal.
- **Live Studio Clock**:
  - Real-time studio clock widget in UTC/local time.
- **Synthesized UI Sound Effects**:
  - Subtle interactive audio synthesizer using native Web Audio API (zero external mp3 assets, toggled via sound button).
- **Social Proof & Testimonials**:
  - Client reviews with verified founder credentials and ratings.
  - Continuous infinite marquee with tech partner logos.
- **Fully Responsive & Accessible**:
  - Smooth mobile drawer menu, clean semantic HTML5, WCAG color contrast, and zero external build step dependencies.
