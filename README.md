## 📚 8 Comprehensive Case Studies

Every project features its own embedded mini case study on the card, an instant deep-dive modal walkthrough, and a dedicated standalone page:

1. **[SSOT: Single Source of Truth Design System](case-studies/ssot.html)**
   - *Domain*: Enterprise Design Systems & Multi-Brand Governance
   - *Impact*: 142 redundant variants consolidated into 48 tokenized components; 60% faster design-to-dev turnaround; zero style drift.
2. **[Kyobee: Plan Selector & Frictionless Checkout](case-studies/kyobee.html)**
   - *Domain*: Hospitality SaaS · Guest Waitlist Management
   - *Impact*: +48% trial-to-paid checkout conversion; bounce rate cut from 67% to 29%; 72% fewer billing inquiries.
3. **[MSfitCentre: Automated Workout Tracker (Gym 2.0)](case-studies/msfitcentre.html)**
   - *Domain*: HealthTech & Mobile App
   - *Impact*: 88% workout session completion rate (vs 40% industry avg); 2.1 sec average logging speed; SUS score 84/100.
4. **[UI/UX 2023 Showcase & Research Framework](case-studies/showcase-2023.html)**
   - *Domain*: Figma Prototype Walkthrough · Node 1042-264
   - *Impact*: 100+ interactive frames with responsive constraints (375px–1440px); 6-phase documented methodology.
5. **[Tactile Mobile Ergonomics & Gesture Flow](case-studies/tactile-mobile.html)**
   - *Domain*: Mobile Interaction & Gesture Lab · Node 2602-39
   - *Impact*: 0% tap miss rate with bottom-sheet thumb ergonomics; 60fps spring physics motion; 100% flow completion.
6. **[iCare: Preventative Health & Telemetry App](case-studies/icare.html)**
   - *Domain*: Healthcare & Mobile UI
   - *Impact*: 90% user comprehension with plain-language health translations; circadian day/night color system; WCAG AA+ compliant.
7. **[Persona-Driven Agri-Commerce Mobile Platform](case-studies/agritech.html)**
   - *Domain*: Rural Agritech & Low-Bandwidth E-Commerce
   - *Impact*: 52% faster checkout; 100% unassisted completion via paper-prototype field testing; 50KB image budget.
8. **[Conversion Redesign Series (Swiggy, Lastcard & Rocketline)](case-studies/conversion-redesigns.html)**
   - *Domain*: Heuristic Evaluations & Conversion Rate Optimization
   - *Impact*: 2.4x higher comprehension; 34+ heuristic violations documented; published UX audit series.

## 🌟 Key Features & Architecture

- **Dark Editorial Aesthetic**: Bespoke dark interface with ambient glow orbs, noise texture, and subtle glassmorphism.
- **Micro-Interactions**: Ambient cursor follower, 3D perspective mouse tilt, real-time clock, smooth navigation drawer.
- **Skills & Toolkit Matrix**: Verified proficiency bars across Design, Research, Collaboration, and Domain Expertise.
- **Career Timeline**: 4+ years of hands-on product problem-solving history.
- **Functional Contact Form**: Direct client inquiry form with input validation and reassurance modal.

## 🚀 How to Run Locally

Open `index.html` directly in any web browser, or start a local server:
```bash

# or
npx serve .
```
Visit `http://localhost:3000`.
